# Text

Código da aula **Text** (Componentes Visuais) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_text_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_text/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-01-text --single-branch https://github.com/R5-Academy/flutter-ui-development.git 06-01-text
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/06-01-text.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
