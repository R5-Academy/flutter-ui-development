# Constraints Prática

Código da aula **Constraints Prática** (Sistema de Layout) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_constraints_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_constraints/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 02-02-constraints-pratica --single-branch https://github.com/R5-Academy/flutter-ui-development.git 02-02-constraints-pratica
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/02-02-constraints-pratica.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
