# FormField

Código da aula **FormField** (Formulários) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_formfield_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_formfield/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 09-06-formfield --single-branch https://github.com/R5-Academy/flutter-ui-development.git 09-06-formfield
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/09-06-formfield.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
