# TextFormField

Código da aula **TextFormField** (Formulários) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_textformfield_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_textformfield/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 09-05-textformfield --single-branch https://github.com/R5-Academy/flutter-ui-development.git 09-05-textformfield
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/09-05-textformfield.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
