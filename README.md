# BottomNavigationBar e NavigationBar

Código da aula **BottomNavigationBar e NavigationBar** (Estrutura da Tela) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplos_codigo_final/` — o projeto **como ficou ao fim da gravação**.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 01-04-bottomnavigationbar-e-navigationbar --single-branch https://github.com/R5-Academy/flutter-ui-development.git 01-04-bottomnavigationbar-e-navigationbar
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/01-04-bottomnavigationbar-e-navigationbar.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
