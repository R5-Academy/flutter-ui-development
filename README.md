- `Layout.png` — material usado na aula.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 01-05-Exercicio --single-branch https://github.com/R5-Academy/flutter-ui-development.git 01-05-Exercicio
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/01-05-Exercicio.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
