# ListView

Código da aula **ListView** (Scrollables) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `lab_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `lab/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 08-02-listview --single-branch https://github.com/R5-Academy/flutter-ui-development.git 08-02-listview
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/08-02-listview.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
