# Wrap

Código da aula **Wrap** (Layouts Flexíveis) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_wrap_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_wrap/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 04-07-wrap --single-branch https://github.com/R5-Academy/flutter-ui-development.git 04-07-wrap
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/04-07-wrap.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
