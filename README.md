# Image

Código da aula **Image** (Componentes Visuais) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_image_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_image/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 06-05-image --single-branch https://github.com/R5-Academy/flutter-ui-development.git 06-05-image
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/06-05-image.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
