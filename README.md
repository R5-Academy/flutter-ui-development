# Container

Código da aula **Container** (Layouts Básicos) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_container_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_container/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 03-01-container --single-branch https://github.com/R5-Academy/flutter-ui-development.git 03-01-container
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/03-01-container.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Índice com todas as aulas do curso: <https://github.com/R5-Academy/flutter-ui-development>
