# Position

Código da aula **Position** (Sistema de Layout) do curso **Flutter UI Development** — R5 Flutter Academy.

## O que tem aqui

- `exemplo_position_codigo_final/` — o projeto **como ficou ao fim da gravação**.
- `exemplo_position/` — o **ponto de partida**: mesmo projeto com a `lib/` no estado em que a aula começa.

## Como baixar

Só esta aula, com git:

```bash
git clone -b 02-05-position --single-branch https://github.com/R5-Academy/flutter-ui-development.git 02-05-position
```

Sem git: [baixar o ZIP](https://github.com/R5-Academy/flutter-ui-development/archive/refs/heads/02-05-position.zip).

Depois, dentro da pasta do projeto: `flutter pub get` e `flutter run`.

Sobre o curso: <https://github.com/R5-Academy/flutter-ui-development>
